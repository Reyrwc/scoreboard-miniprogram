## Variant: 极简工具型

### Design stance
参考 iOS 原生设计语言，极简、干净、工具感强。

### Key choices
- **Layout**: 列表式，每行一个玩家
- **Typography**: 系统字体，iOS 风格的字号和间距
- **Color**: 浅灰背景 + 白色卡片，蓝/绿/红三色
- **Interaction**: 底部弹窗（iOS Sheet），点击行记分

### 设计原则
- 遵循 iOS 设计规范（圆角、间距、字号）
- 无多余装饰，聚焦信息本身
- 底部固定操作栏，符合拇指操作习惯

### Best for
习惯 iOS 风格的用户，追求简洁高效
